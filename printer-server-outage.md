# Incident: Printer Server Outage Across All Floors

**Platform:** ServiceDesk Simulator
**Severity:** High
**Status:** Resolved

## Summary
Printers on every floor stopped working, preventing the company from carrying out daily operations.

## Troubleshooting and Resolution
1. Recognized that the outage affected all floors at once, which pointed to the shared printer server rather than individual printers.
2. Went to the server room and rebooted the printer server.
3. Confirmed the printers were working again across the floors.

## Outcome
Printing was restored company-wide and daily operations resumed. Ticket closed.

## Takeaways
- When many devices fail at once, look for the shared point of failure first.
- A single server can affect the whole company, so outages like this deserve fast prioritization.
